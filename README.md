# SendReady

Modern Android video compression application built with Kotlin and Jetpack Compose.

## Features

- Material Design 3
- AMOLED Dark Mode
- Modern MVVM Architecture
- Hilt Dependency Injection
- Media3 Integration
- Fast Video Compression
- Compression Presets
- Batch Processing
- Compression History
- Beautiful Animations

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Hilt
- Room
- DataStore
- Navigation Compose
- Media3
- Coroutines
